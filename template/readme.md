# Top bar template

Sample resolution for a custom Studio top bar background:

- **1360 × 52 px** PNG (recommended)
- The editor stretches it with `background-size: cover`, so other widths work, but design against 1360×52.

Files:

- [`topbar-1360x52.png`](topbar-1360x52.png) — sample strip (purple / green bands)
- Also served in the app at `/template/topbar-1360x52.png` (download from **Project → Appearance**)

Replace this PNG with your art, then upload it in **Settings → Appearance → Top bar image**.
